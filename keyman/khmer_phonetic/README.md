Khmer Phonetic keyboard
==============

Description
-----------
Type Khmer by sound, written in Latin letters: sousdey becomes សួស្តី.
Spelling is forgiving, so sousdey, suosdei and susadey all reach the same word.
A 20,000 word dictionary supplies predictions on phones and tablets, from the
related package pakrinha.km.khmerphonetic.

Unlike the NiDA-based Khmer layouts, this keyboard does not require the user to
learn a key arrangement, which makes it usable by Khmer speakers who currently
type romanised Khmer because they never learned the standard layout.
