You write the sound. The keyboard writes the Khmer. អ្នកសរសេរសំឡេង ក្ដារចុចសរសេរជាអក្សរខ្មែរ។

No. Conversion, suggestions and learning all run on your device. The page downloads its word list from this site and sends nothing back. ទេ។ ការបម្លែង ការណែនាំពាក្យ និងការរៀន ដំណើរការនៅលើឧបករណ៍របស់អ្នកទាំងអស់។ ទំព័រនេះគ្រាន់តែទាញយកបញ្ជីពាក្យពីគេហទំព័រនេះ ហើយមិនបញ្ជូនអ្វីត្រឡប់ទៅវិញទេ។

How is it different from the standard Khmer keyboard?តើវាខុសពីក្ដារចុចខ្មែរស្តង់ដារយ៉ាងដូចម្ដេច?

The standard layout puts each Khmer letter on a fixed key, and many letters need Shift or a second layer, so you have to memorise where everything is. Here you spell the sound with Latin letters you already know and choose the word. ក្ដារចុចស្តង់ដារដាក់អក្សរខ្មែរនីមួយៗនៅលើគ្រាប់ចុចថេរ ហើយអក្សរជាច្រើនត្រូវប្រើ Shift ឬប្ដូរទៅទំព័រទីពីរ ដូច្នេះអ្នកត្រូវទន្ទេញទីតាំងរបស់វាទាំងអស់។ នៅទីនេះ អ្នកសរសេរសំឡេងដោយអក្សរឡាតាំងដែលអ្នកស្គាល់រួចហើយ រួចជ្រើសរើសពាក្យ។

A word I need doesn't appear.ពាក្យដែលខ្ញុំត្រូវការ មិនលេចឡើង។

Keep typing it letter by letter. Any Khmer syllable can be written that way, subscripts included, and the keyboard remembers the word for next time. In the web version you can also add a word with your own spelling under My words. If a common word is missing, report it on GitHub so it can be added for everyone. បន្តវាយវាតាមអក្សរនីមួយៗ។ ព្យាង្គខ្មែរណាក៏អាចសរសេរតាមវិធីនេះបាន រួមទាំងជើងអក្សរ ហើយក្ដារចុចនឹងចងចាំពាក្យនោះសម្រាប់លើកក្រោយ។ ក្នុងកំណែវេប អ្នកក៏អាចបន្ថែមពាក្យជាមួយអក្ខរាវិរុទ្ធរបស់អ្នកផ្ទាល់ នៅក្នុងផ្នែក «ពាក្យរបស់ខ្ញុំ»។ ប្រសិនបើពាក្យទូទៅណាមួយបាត់ សូមរាយការណ៍នៅលើ GitHub ដើម្បីបន្ថែមវាសម្រាប់អ្នកទាំងអស់គ្នា។

Why isn't it on Google Play or the App Store?ហេតុអ្វីមិនមាននៅលើ Google Play ឬ App Store?

It hasn't been published to either store yet. The Android app installs directly from its APK file. On iPhone it is sideloaded with SideStore: a free Apple ID signs apps for seven days at a time, and SideStore renews the signature on the phone by itself. វាមិនទាន់បានដាក់ឲ្យប្រើនៅលើហាងទាំងពីរនៅឡើយទេ។ កម្មវិធី Android ដំឡើងដោយផ្ទាល់ពីឯកសារ APK។ នៅលើ iPhone វាត្រូវបានដំឡើងតាម SideStore៖ Apple ID ឥតគិតថ្លៃចុះហត្ថលេខាលើកម្មវិធីបានរយៈពេលប្រាំពីរថ្ងៃម្ដង ហើយ SideStore បន្តហត្ថលេខានោះនៅលើទូរស័ព្ទដោយស្វ័យប្រវត្តិ។

Can I use it in Telegram, Messenger or Word?តើខ្ញុំអាចប្រើវាក្នុង Telegram Messenger ឬ Word បានទេ?

Yes, through the Android app, the iPhone app or the Keyman package, which all work as system keyboards. The web version types into its own page: copy the result and paste it wherever you need it. បាន តាមរយៈកម្មវិធី Android កម្មវិធី iPhone ឬកញ្ចប់ Keyman ដែលទាំងអស់ដំណើរការជាក្ដារចុចរបស់ប្រព័ន្ធ។ កំណែវេបវាយក្នុងទំព័ររបស់វាផ្ទាល់៖ ចម្លងលទ្ធផល ហើយបិទភ្ជាប់ទៅកន្លែងដែលអ្នកត្រូវការ។

Which romanization does it follow?តើវាប្រើប្រព័ន្ធសរសេរឡាតាំងមួយណា?
