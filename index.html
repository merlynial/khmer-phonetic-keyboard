Only the first time. After your first visit the web version is stored on your device, and the Android and iPhone apps never need a connection. ត្រូវការតែលើកដំបូងប៉ុណ្ណោះ។ ក្រោយបើកលើកដំបូង កំណែវេបត្រូវរក្សាទុកក្នុងឧបករណ៍របស់អ្នក ហើយកម្មវិធី Android និង iPhone មិនត្រូវការអ៊ីនធឺណិតសោះ។

Does anything I type leave my device?អ្វីដែលខ្ញុំវាយ ត្រូវបានបញ្ជូនចេញពីឧបករណ៍ទេ?

No. Conversion, suggestions and learning all run on your device. The page downloads its word list from this site and sends nothing back. ទេ។ ការបម្លែង ការណែនាំពាក្យ និងការចងចាំពាក្យ សុទ្ធតែដំណើរការលើឧបករណ៍របស់អ្នក។ ទំព័រនេះគ្រាន់តែទាញយកបញ្ជីពាក្យពីគេហទំព័រនេះ ហើយមិនផ្ញើអ្វីត្រឡប់ទៅវិញទេ។

How is it different from the standard Khmer keyboard?តើវាខុសពីក្ដារចុចខ្មែរធម្មតាយ៉ាងដូចម្ដេច?

The standard layout puts each Khmer letter on a fixed key, and many letters need Shift or a second layer, so you have to memorise where everything is. Here you spell the sound with Latin letters you already know and choose the word. ក្ដារចុចខ្មែរធម្មតា ដាក់អក្សរខ្មែរនីមួយៗលើគ្រាប់ចុចជាប់លាប់មួយ ហើយអក្សរជាច្រើនត្រូវចុច Shift ឬប្ដូរទៅទំព័រទីពីរ ដូច្នេះអ្នកត្រូវទន្ទេញទីតាំងរបស់វា។ ចំណែកក្ដារចុចនេះ អ្នកគ្រាន់តែវាយសូរជាអក្សរអង់គ្លេសដែលអ្នកស្គាល់ស្រាប់ រួចរើសពាក្យ។

A word I need doesn't appear.ពាក្យដែលខ្ញុំត្រូវការ មិនលោតមក។

Keep typing it letter by letter. Any Khmer syllable can be written that way, subscripts included, and the keyboard remembers the word for next time. In the web version you can also add a word with your own spelling under My words. If a common word is missing, report it on GitHub so it can be added for everyone. វាយវាតាមអក្សរម្ដងមួយៗទៅ។ ព្យាង្គខ្មែរណាក៏អាចវាយតាមរបៀបនេះបាន រួមទាំងជើងអក្សរ ហើយក្ដារចុចនឹងចាំពាក្យនោះសម្រាប់លើកក្រោយ។ ក្នុងកំណែវេប អ្នកក៏អាចបន្ថែមពាក្យជាមួយរបៀបប្រកបរបស់អ្នក នៅក្នុងផ្នែក «ពាក្យរបស់ខ្ញុំ»។ បើពាក្យទូទៅណាមួយខ្វះ សូមរាយការណ៍នៅលើ GitHub ដើម្បីបន្ថែមវាសម្រាប់អ្នកទាំងអស់គ្នា។

Why isn't it on Google Play or the App Store?ហេតុអ្វីមិនមាននៅលើ Google Play ឬ App Store?

It hasn't been published to either store yet. The Android app installs directly from its APK file. On iPhone it is sideloaded with SideStore: a free Apple ID signs apps for seven days at a time, and SideStore renews the signature on the phone by itself. វាមិនទាន់បានដាក់លើហាងណាមួយនៅឡើយទេ។ កម្មវិធី Android ដំឡើងពីឯកសារ APK ដោយផ្ទាល់។ សម្រាប់ iPhone ត្រូវដំឡើងតាម SideStore៖ Apple ID ឥតគិតថ្លៃចុះហត្ថលេខាលើកម្មវិធីបានម្ដង ៧ ថ្ងៃ ហើយ SideStore បន្តហត្ថលេខានោះលើទូរស័ព្ទដោយខ្លួនឯង។

Can I use it in Telegram, Messenger or Word?ប្រើក្នុង Telegram Messenger ឬ Word បានទេ?

Yes, through the Android app, the iPhone app or the Keyman package, which all work as system keyboards. The web version types into its own page: copy the result and paste it wherever you need it. បាន តាមរយៈកម្មវិធី Android កម្មវិធី iPhone ឬកញ្ចប់ Keyman ដែលដំណើរការជាក្ដារចុចរបស់ប្រព័ន្ធ។ ចំណែកកំណែវេប វាយបានតែក្នុងទំព័ររបស់វា៖ ចម្លងអត្ថបទ រួចយកទៅបិទភ្ជាប់កន្លែងដែលអ្នកចង់បាន។

Which romanization does it follow?តើវាប្រើក្បួនសរសេរខ្មែរជាអក្សរអង់គ្លេសមួយណា?

None strictly. Suggestions accept the loose spellings people use in chat. Underneath there is one exact scheme for typing letter by letter, close to common chat spelling, and the typing guide lays it out. មិនប្រកាន់ក្បួនណាមួយតឹងរ៉ឹងទេ។ ពាក្យណែនាំទទួលយករបៀបប្រកបធូររលុងដែលមនុស្សប្រើពេលឆាត។ នៅពីក្រោយ មានក្បួនច្បាស់លាស់មួយសម្រាប់វាយតាមអក្សរម្ដងមួយៗ ដែលស្រដៀងនឹងការប្រកបពេលឆាត ហើយមានពន្យល់ក្នុងទំព័ររបៀបវាយ។
