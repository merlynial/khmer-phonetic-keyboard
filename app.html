Consonantsព្យញ្ជនៈ

Vowels (type after a consonant)ស្រៈ (វាយបន្ទាប់ពីព្យញ្ជនៈ)

Signs and punctuationសញ្ញា និងវណ្ណយុត្តិ

Clusters: type consonants together with no vowel between them: skl → ស្ក្ល, knhom → ក្ញុំ. To stop stacking, put a space or a . between them. Inherent vowel: a consonant alone carries its built-in vowel, so k → ក and ka → ក too. Series shifters: * = ៉ (m*aong → ម៉ោង), ` = ៊ (s` → ស៊). Capitals matter: d = ដ but D = ឌ, n = ន but N = ណ, l = ល but L = ឡ. ជើងអក្សរ៖ វាយព្យញ្ជនៈជាប់គ្នាដោយគ្មានស្រៈនៅចន្លោះ៖ skl → ស្ក្ល, knhom → ក្ញុំ។ ដើម្បីកុំឲ្យដាក់ជើង សូមដាក់ដកឃ្លា ឬ . នៅចន្លោះ។ ស្រៈក្នុងតួ៖ ព្យញ្ជនៈតែឯងមានស្រៈក្នុងខ្លួន ដូច្នេះ k → ក ហើយ ka → ក ដូចគ្នា។ សញ្ញាប្ដូរវគ្គ៖ * = ៉ (m*aong → ម៉ោង), ` = ៊ (s` → ស៊)។ អក្សរធំមានន័យ៖ d = ដ ប៉ុន្តែ D = ឌ, n = ន ប៉ុន្តែ N = ណ, l = ល ប៉ុន្តែ L = ឡ។
