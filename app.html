Typing chart: how to type each soundតារាងវាយ៖ របៀបវាយសូរនីមួយៗ

Consonantsព្យញ្ជនៈ

Vowels (type after a consonant)ស្រៈ (វាយបន្ទាប់ពីព្យញ្ជនៈ)

Signs and punctuationសញ្ញា និងវណ្ណយុត្តិ

Clusters: type consonants together with no vowel between them: skl → ស្ក្ល, knhom → ក្ញុំ. To stop stacking, put a space or a . between them. Inherent vowel: a consonant alone carries its built-in vowel, so k → ក and ka → ក too. Series shifters: * = ៉ (m*aong → ម៉ោង), ` = ៊ (s` → ស៊). Capitals matter: d = ដ but D = ឌ, n = ន but N = ណ, l = ល but L = ឡ. ព្យញ្ជនៈផ្ទួន៖ វាយព្យញ្ជនៈជាប់គ្នាដោយគ្មានស្រៈនៅកណ្ដាល៖ skl → ស្ក្ល knhom → ក្ញុំ។ បើមិនចង់ឱ្យដាក់ជើង ដាក់ដកឃ្លា ឬ . នៅកណ្ដាល។ សំឡេងដើម៖ ព្យញ្ជនៈនៅតែឯងមានសំឡេងដើមរបស់វា ដូច្នេះ k → ក ហើយ ka → ក ដូចគ្នា។ សញ្ញាប្ដូរវគ្គ៖ * = ៉ (m*aong → ម៉ោង) និង ` = ៊ (s` → ស៊)។ អក្សរធំខុសពីអក្សរតូច៖ d = ដ តែ D = ឌ។ n = ន តែ N = ណ។ l = ល តែ L = ឡ។
