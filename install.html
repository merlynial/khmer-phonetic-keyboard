Install on your phone or computer

Type Khmer by sound in any app — Telegram, Messenger, Word, your browser

The web version converts text you type into a box. This page installs the same romanization as a real system keyboard, so it works everywhere your phone or computer accepts typing.

On Android that is a standalone app. On iPhone and Windows it goes through Keyman, a free and open-source keyboarding app from SIL — you install Keyman once, then add this keyboard to it.

Android — the app

Download Khmer Phonetic (3.3 MB)
  1. Open this page on your phone and tap the button above.
  2. Tap the downloaded file to install. Android will ask you to allow installing apps from your browser — this app is not on Google Play, so that step is expected.
  3. Open Khmer Phonetic from your app list. It walks you through turning the keyboard on and choosing it.
  4. Anywhere you type, tap the globe key to switch to it.

This one has the sound-matching suggestion bar from the web version: type sousdey, suosdei or suastei and it still finds សួស្តី. It learns the words and spellings you use, and keeps them on the phone.

iPhone, iPad and Windows — the Keyman package

Khmer Phonetic keyboard Khmer dictionary (optional)

One package, every platform: iPhone, iPad, Windows, macOS, Linux — and Android too, if you would rather use Keyman than install the app. The dictionary adds a word-suggestion bar on phones and tablets.

The Keyman keyboard converts spelling exactly, with no sound matching — sousdey will not find សួស្តី there the way it does in the app and on the web.

iPhone and iPad

  1. Install Keyman from the App Store.
  2. Open this page on the device and tap the download button above. Choose to open the file in Keyman.
  3. In Settings → General → Keyboard → Keyboards, add Keyman and allow full access — iOS requires this for any third-party keyboard.
  4. Hold the globe key in any app to switch to Khmer Phonetic.

Windows

  1. Install Keyman for Windows.
  2. Download the keyboard package and double-click the .kmp file.
  3. Switch to it from the Keyman icon in the system tray, or with the Windows language switcher.

Word suggestions are a phone and tablet feature; on Windows the keyboard types Khmer directly with no suggestion bar.

How to type

Write the word the way it sounds. suastei gives សួស្តី, arkun gives អរគុណ, khnhom gives ខ្ញុំ.

Consonants typed together with no vowel between them stack with coeng automatically. Type . to break a cluster: ka.mpujaa gives កម្ពុជា.

Capitals reach the second-series consonants — d ដ against D ឌ, n ន against N ណ. On a phone, hold the key instead of using Shift.

The full table is in the welcome page Keyman shows after installing, and on the web version.

Which one behaves like the web version

The Android app does. It carries the same sound-matching suggestions as this site — loose spellings still find the right word — and it learns from what you pick.

The Keyman package converts letters exactly as typed, with no guessing, and suggests whole words from a 20,000 word frequency list once the dictionary is installed. That is the trade for reaching iPhone and Windows at all.

All three use the same romanization, so what you already know carries over. Both builds are checked against the web version automatically — tens of thousands of spellings on every build, and any disagreement fails the build.
