The app has the sound-matching suggestion bar from the web version: type sousdey, suosdei or suastei and it still finds សួស្តី.   2. Install SideStore on the iPhone, then open the .ipa in it. SideStore signs it with your own Apple ID; no developer account is needed. ដំឡើង SideStore នៅលើ iPhone រួចបើកឯកសារ .ipa នៅក្នុងវា។ SideStore ចុះហត្ថលេខាលើវាដោយ Apple ID របស់អ្នកផ្ទាល់ ដោយមិនត្រូវការគណនីអ្នកអភិវឌ្ឍន៍ទេ។
  3. Go to Settings → General → Keyboard → Keyboards → Add New Keyboard → Khmer Phonetic. ចូលទៅ Settings → General → Keyboard → Keyboards → Add New Keyboard → Khmer Phonetic។
  4. Hold the globe key in any app to switch to it. It never asks for Allow Full Access. ចុចសង្កត់គ្រាប់ចុចរូបផែនដីក្នុងកម្មវិធីណាមួយ ដើម្បីប្ដូរមកក្ដារចុចនេះ។ វាមិនដែលសុំ «Allow Full Access» ទេ។

How to typeរបៀបវាយ

Write the word the way it sounds. suastei gives សួស្តី, arkun gives អរគុណ, khnhom gives ខ្ញុំ. សរសេរពាក្យតាមសំឡេងរបស់វា។ suastei ផ្ដល់ សួស្តី, arkun ផ្ដល់ អរគុណ, khnhom ផ្ដល់ ខ្ញុំ។

Consonants typed together with no vowel between them stack automatically. Type . to break a cluster: ka.mpujaa gives កម្ពុជា. ព្យញ្ជនៈដែលវាយជាប់គ្នាដោយគ្មានស្រៈនៅចន្លោះ នឹងក្លាយជាជើងដោយស្វ័យប្រវត្តិ។ វាយ . ដើម្បីបំបែក៖ ka.mpujaa ផ្ដល់ កម្ពុជា។

Capitals reach the second-series consonants: d ដ against D ឌ, n ន against N ណ. In the phone apps, hold the key instead of using Shift. អក្សរធំប្រើសម្រាប់ព្យញ្ជនៈមួយចំនួនទៀត៖ d ដ និង D ឌ, n ន និង N ណ។ ក្នុងកម្មវិធីទូរស័ព្ទ ចុចសង្កត់គ្រាប់ចុចជំនួសការប្រើ Shift។

The full table is in the typing guide, and in the welcome page Keyman shows after installing. តារាងពេញលេញមាននៅក្នុងមេរៀនវាយ និងនៅក្នុងទំព័រស្វាគមន៍ដែល Keyman បង្ហាញក្រោយពេលដំឡើង។
